Install AmbWave

This installs the AmbWave ambient instrument on an M-VAVE FM-1, using Felucca's existing updater. Use Chrome or Edge on a computer, over HTTPS or localhost. No Python is needed.

  1. Back up projects, presets, samples and settings with your current firmware's backup tools. Keep the backup private and verify that the download finished.
  2. Keep your previously working firmware package for rollback. Close other MIDI editors and installers.
  3. Connect the FM-1 directly by USB with stable power. Keep it connected until restart and verification finish.

Open Felucca's backup editor (for compatible running firmware). Close its tab before installing. Complete AmbWave scene recall is not implemented; live held notes and macro state are not a saved scene.

If an update stops


Keep this page open until it reports completion or an error. If interrupted, reconnect and install the same verified package again;
the updater can resume from its loader. If the running firmware does not return, power-cycle the FM-1 and check it again.
If no installer finds it, follow the recovery guide. Recovery is a separate procedure.


After completion, check the AMBWAVE splash and ABOUT version on the device, then try TIDE and release your notes.
The compatible FM-1_900 identifier alone does not identify AmbWave.
